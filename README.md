# The Lya Edit — Lya Nguyen's Portfolio

A magazine-style creative portfolio for **Lya Nguyen** — marketing, content & strategy, International Business graduate based in Taipei.

Static site: plain HTML, CSS and JavaScript, no build step.

- `index.html` — content
- `style.css` — design
- `main.js` — interactions (draggable photo wall, counters, lightbox, reveal-on-scroll)
- `assets/` — images and résumé

Run locally: open `index.html`, or `python -m http.server` in this folder.
